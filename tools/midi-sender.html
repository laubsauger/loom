MIDI Sender

A dev tool for exercising Loom's MIDI In node and MIDI-learn without a hardware controller. It is not part of the app: it is served by the dev server only and is not included in a production build.

How to use it

  1. Create a virtual MIDI port on this machine (see below) — a browser tab cannot send MIDI to itself without one, because Web MIDI outputs go to the operating system and Web MIDI inputs come back from it.
  2. Open this page, press Enable MIDI, and pick that virtual port as the output.
  3. In Loom, drop a MIDI In node, open the inspector's MIDI section, press Enable MIDI, and pick the same virtual port (or leave it on Any input).
  4. Press Add control, then Learn, then move a knob on this page. The row binds to that CC.
  5. Rename the row to something you would actually type — cutoff — and drive a parameter with midi1:cutoff.

Creating a virtual MIDI port

  • macOS — no install needed. Open Audio MIDI Setup, choose Window → Show MIDI Studio, double-click IAC Driver, and tick Device is online. Its bus then appears as both an input and an output.
  • Windows — install loopMIDI (Tobias Erichsen, free) and add a port. There is no built-in equivalent.
  • Linux — ALSA has one built in: sudo modprobe snd-virmidi gives you a set of virtual ports, or run a2jmidid / a JACK setup if you already use one.

Web MIDI needs a secure context. http://localhost counts as one, so the dev server is fine. Safari has no Web MIDI at any version, so this page will say so there — which is the same thing Loom itself says, for the same reason.
